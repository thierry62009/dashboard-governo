# Segurança

## Como relatar uma falha de segurança

Use o relato privado do GitHub: na página do repositório, abra a aba **Security** e clique em
**Report a vulnerability**. O relato fica visível só para quem mantém o projeto.

Não publique os detalhes da falha numa Issue: as Issues são públicas.

Erros nos dados ou nos textos do site (que não sejam falhas de segurança) podem ser avisados
normalmente pelas Issues do projeto.
